# Loan Sales Analysis Dashboard

This interactive Power BI dashboard designed to monitor retail loan disbursements, banking partner distribution, regional penetration, sales agent throughput, and product-level portfolio performance.

---

## 📌 Dashboard Overview

![Loan Sales Analysis Dashboard] https://github.com/suneel-kumar88/Loan-Sales-Analysis-Dashboard/blob/1736985f79f3ee1a9d13b5c061c617d1c6c2830b/Loan%20Sales%20Analysis.png



This dashboard provides retail banking heads, credit sales managers, and financial analysts with high-level and granular visibility into total loan volumes, partner bank allocations, top-performing sales representatives, and geographical performance across Indian states and cities.

---

## 🎛️ Interactive Slicers & Filters

* **Time Hierarchy:** Multi-level date selector (`Year, Quarter, Month, Day`).
* **Bank Slicer:** Partner bank filtering across institutional partners.
* **Demographics Slicers:** `States`, `Region`, and `Product` dropdown filters.
* **Sales Team Slicer:** Dynamic filtering by individual sales representatives.

---

## 🛠️️ Built With

* **BI Tool:** Microsoft Power BI Desktop
* **Data Modeling:** Power Query 
* **Calculations:** DAX (Data Analysis Expressions) for Total Loan Volume, Bank Percentage of Total (%GT), and Regional Aggregations
* **UI/UX Design:** Dark teal banking executive theme with high-contrast bar charts and distribution donuts
